# Starbucks India Business Intelligence Dashboard

## Project Overview
This project presents an advanced Excel dashboard analyzing Starbucks India’s operations using real transactional data across 12 months. It includes KPIs, visual charts, pivot tables, and interactive slicers.

## Key Insights:
- Total Revenue: ₹319M across 354 stores
- Most revenue comes from Coffee (55%)
- Bangalore, Jaipur, and Chennai are top-performing cities
- Seasonal revenue peaks in May and September

## Features:
- KPI Dashboard with Revenue, Footfall, Avg Spend, etc.
- Monthly revenue trend line
- Product category revenue pie chart
- Top cities bar chart
- Revenue vs Footfall scatter plot
- Slicers for City and Store Type
- Interactive and clean layout

## Tools Used:
- Microsoft Excel (Pivot Tables, Charts, Slicers, Dashboarding)

## Project Goal:
To generate actionable insights into Starbucks India’s sales performance, customer behavior, and city-wise/store-wise profitability.
